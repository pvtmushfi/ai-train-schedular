# 🚆 AI Train Scheduling System

A full-stack AI-powered railway management system built using **React, FastAPI, and MySQL**.  
It provides real-time train tracking, AI-based delay prediction, analytics, and scheduling optimization.

---

## 📌 Features

- 🚉 Live Train Tracking System
- 🤖 AI-Based Delay Prediction
- 📊 Analytics Dashboard
- 🧠 Smart Train Scheduling
- 🔍 Search & Filter Trains
- 🔐 Login & Authentication System
- 📱 Fully Responsive UI

---

## 🛠️ Tech Stack

### Frontend:
- React.js
- JavaScript
- CSS

### Backend:
- FastAPI (Python)
- REST APIs

### Database:
- MySQL
